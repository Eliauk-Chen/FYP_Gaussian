# 结果文件索引

此目录为已有实验的聚合文件副本，没有重新训练或改写指标。来源及 SHA-256 见 [publication_manifest.json](publication_manifest.json)。

- `clean/`：干净输入、数据聚合审计与检查。
- `width/`：共享宽度扫描、锁定参数与验证曲线。
- `multiwidth/`：单宽度、定向及随机多宽度对照；包括全部随机配置的汇总。
- `cycle/`：响应库 Cycle 波动的配对结果与检查。

各阶段协议不同，不跨阶段拼接为同一次测试。多宽度与 Cycle 的发布表使用 Macro-F1；其他 CSV 的指标名称以列名为准。当前保留的是开发集外层评估，不是新独立确认测试。
