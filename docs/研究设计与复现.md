# 研究设计与复现

## 输入与模型

原始 21 个二维关键点经腕点居中及 RMS 归一化得到 42 维。StandardScaler、PCA 16 维和 MinMax 只使用当前折训练部分拟合。归一化值裁剪至 [0,1]，量化为 0–255 等级。每个输入维度查询 16 路响应。

对训练响应 H[n,d,k] 沿样本维求均值和总体标准差（ddof=0），使用数值保护下限 1e-12 标准化。实际实现以外部 `src/rbf_hardware/modeling/joint_gaussian.py` 及各保存模型参数为准。

校准目标为 T[n,d,j] = exp(-(x[n,d]-c[j,d])²/(2σ[j]²))。拼接截距后 Z[d] 为 N×17，每个维度校准矩阵 A[d] 为 17×256：

```
A[d] = solve(Z[d].T @ Z[d] + λ diag(0,1,…,1), Z[d].T @ T[d])
S[n,d,j] = clip((Z[d] @ A[d])[n,j], saved_lower, saved_upper)
Φ[n,j] = exp(sum_d log(S[n,d,j]))
```

截距不受正则惩罚。16 组矩阵总形状为 16×17×256。边界使用模型保存值；对数乘积以 float64 计算，再转 float32，仍需检查最终小响应的下溢。随后训练 Ridge 读出四类分数，不称为概率。

## 扰动协议

- 定位抖动：在关键点上加入以干净手部 RMS 为尺度的高斯噪声（包括腕点），再居中、归一化。
- 缺失：抽取非腕点，以训练集类别无关均值填补；该协议保持原有尺度，不再归一化，因此是受控缺失代理，不代表所有实际检测器失败方式。
- 离群点：选取非腕点，沿随机方向施加固定 1 RMS 的偏移，再归一化。
- Cycle：每个样本抽取一个 Cycle，同一 Cycle 用于其所有维度与通道；模型间配对，不额外叠加假定的 1%–5% 噪声。

单宽度候选池为 [0.125, 0.175, 0.25, 0.3, 0.35, 0.5, 0.7, 1]。多宽度保持 256 个节点，逐节点从同一池选值，严格验证改善才接受；最多两轮、每个搜索 90 秒上限，并保留 10 个随机配置。Ridge alpha 网格由代码共享，锁定设置见 results 中的配置文件。选择指标是验证集跨规定强度（含干净）的平均 Macro-F1。

## 分阶段运行

在仓库根目录、安装 README 中依赖并准备输入后，按顺序运行：

```bash
python check_reproduction_inputs.py --stage clean
python hagrid_hardware_clean.py
python check_reproduction_inputs.py --stage perturbations
python hagrid_hardware_perturbations.py
python check_reproduction_inputs.py --stage width
python hagrid_hardware_width_scan.py
python check_reproduction_inputs.py --stage multiwidth
python hagrid_hardware_multiwidth.py
python check_reproduction_inputs.py --stage cycle
python hagrid_hardware_cycle.py
```

脚本为保护旧结果拒绝已有输出目录。请在新克隆的工作目录重跑；已有工作站结果不要删除。部分脚本支持 `--out`，但这不会自动修改后续脚本的固定上游路径。后续阶段还会检查上游预测与指标文件，所以只有模型文件不足以完整运行。预检查仅覆盖主要依赖，不替代样本对齐审计。

当前验证环境为 Python 3.10；依赖见 requirements-hagrid.txt。无需修改系统 GPU 驱动。时间上限搜索可能随机器速度产生不同完成配置数，应同时记录搜索轨迹。已发布结果是原实验文件副本，本次整理没有重训。

## 解释边界

使用的是复用开发数据的嵌套外层评估，不是新独立官方测试集。宽度变化是软件校准目标变化。响应均值使用全部 400 Cycle，当前 Cycle 评估不是未见 Cycle 的泛化证明。后续应预先留出 Cycle，并比较均值校准与 Cycle 感知训练，完成后再报告结果。
