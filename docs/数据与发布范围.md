# 数据来源与发布范围

## 手势数据

来源：[HaGRID 官方项目](https://github.com/hukenovs/hagrid)。当前关键点开发子集保留 786 / 800 个候选；自动关键点不是人工关键点真值。每个保留样本对应一个用户，四类数目为 fist 192、like 196、peace 198、ok 200。

其原始来源中 official train 保留 589、official val 保留 197。当前在这批开发数据内部建立三折用户互斥的训练／验证／外层评估划分：395/133/258、391/131/264、392/130/264。不能将外层评估改称为官方 test。14 个未保留样本未补齐；失败样本排除会限制结论适用范围。

版本与源文件追踪以聚合审计及本地原始清单为准；不将当前小子集包装为官方完整数据集。用户 ID、图片 ID 与图片路径等逐样本信息留在本地，不上传 GitHub。

## 器件响应数据

外部 rbf_hardware 项目的 `hardware_response_samples.npz` 提供 256 输入等级 × 400 Cycle × 16 通道。等级对应量化输入，Cycle 对应重复响应记录，通道对应不同响应通道。本次工作使用已有响应库，未重新采集硬件数据，也未独立追溯验证最初实验工作簿。响应库及外部源代码未随本仓库再分发。
